# Gallery - 免费的 Tailwind CSS 和 Next.js 网站模板
#### 预览

 - [演示](https://themewagon.github.io/gallery/)

#### 下载
 - [从 ThemeWagon 下载](https://themewagon.com/themes/gallery/)

## 开始使用

1. 克隆仓库
```
git clone https://github.com/themewagon/gallery.git
```
2. 安装依赖
```
npm i
```
3. 运行开发服务器：

```bash
npm run dev
# 或
yarn dev
# 或
pnpm dev
# 或
bun dev
```
